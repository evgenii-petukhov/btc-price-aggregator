# BTC Price Aggregator

Returns the price of a crypto instrument (`BtcUsd`, `EthUsd`) for a given hour, aggregated from several exchanges (Bitstamp, Bitfinex). Results are stored in a local SQLite database, so repeating a request is served from the datastore instead of the exchange APIs.

## Quick start

Prerequisites: .NET 10 SDK and Node.js 24+.

The backend serves the built frontend from `wwwroot`.

```bash
dotnet dev-certs https --trust # once, so the browser trusts the HTTPS endpoint
cd frontend
npm install
npm run build                  # writes to backend/PriceAggregator.API/wwwroot
cd ../backend/PriceAggregator.API
dotnet run
```

Then open <https://127.0.0.1:5000>. Swagger UI is at <https://127.0.0.1:5000/swagger>.

## Backend

ASP.NET Core Web API (.NET 10) with a SQLite database (`prices.db`), which is created automatically on startup.

The API listens on `https://127.0.0.1:5000`. The URL can be changed in `backend/PriceAggregator.API/appsettings.json`.

## Frontend

Angular 22 single-page app written in TypeScript and tested with Vitest. It uses standalone components, signals, and reactive forms.

**Communication with the backend.** The frontend calls `GET /api/Price?date=<ISO UTC>&instrument=<BtcUsd|EthUsd>` over HTTPS using Angular's `HttpClient`, through a TypeScript client generated by NSwag (`frontend/src/api-client/api-client.ts`, configured in `api.nswag`). The base URL is the `API_URL` constant in `frontend/src/app/app.config.ts`.

## Assumptions

- Prices are hourly candles. The requested timestamp is truncated to the start of its UTC hour, and the **close** price of that candle is used for each source.
- The timestamp entered in the UI is interpreted as UTC.
- The aggregated price is the average of the source prices. The backend returns only per-source prices, so the average is computed in the frontend.
- "Result source" is *Cache / datastore* only if every source was already stored. If at least one source had to be fetched, it shows *External APIs*.
- If no source has data for the requested hour (for example a date before the exchanges' history, or an hour that hasn't happened yet), the API responds with `200` and an empty `prices` array, and the UI shows *n/a*. If only some sources have data, only those are returned. Empty results are not stored, so such requests always go to the exchange APIs.
- Supported instruments are `BtcUsd` and `EthUsd`; supported sources are Bitstamp and Bitfinex.
- No authentication is required, and the backend allows CORS from any origin (only needed when the dev server on `:4200` calls the API; suitable for local development only).
- The backend does not retry failed exchange calls: if an exchange is unavailable, the request fails and the UI shows the error.
